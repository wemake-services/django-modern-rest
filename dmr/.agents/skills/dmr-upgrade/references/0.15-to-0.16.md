# Upgrade django-modern-rest from 0.15.0 to 0.16.0

Source: `CHANGELOG.md`, release `0.16.0` (unreleased at the time of writing,
re-read the `0.16.0` section of `CHANGELOG.md` for the final list).
Breaking changes for this release are listed in `CHANGELOG.md` under `0.16.0`.

Read this file only while upgrading across this release. Apply every item,
search the whole project (including tests and fixtures) for each one.

## Prompt

You are migrating a Python project from `django-modern-rest` 0.15.0 to 0.16.0.
Load the documentation for the installed version, `llms.txt` lists every page:
https://django-modern-rest.readthedocs.io/en/latest/llms.txt

Apply **all** of the following breaking changes to the codebase.
For each change, search the entire project (including tests, fixtures, and
any helper modules) before editing.

---

### 1. `Controller.as_view()` raises for abstract controllers

`Controller.as_view` now raises `EndpointMetadataError` when the controller
is abstract: it has no exact serializer type (for example, a generic base
class still parametrized with a type var) or it has no endpoints.
Such controllers used to be added to `Router` and `urlpatterns` silently
and then failed on every request.

Find every `.as_view()` call and every `Router` / `path()` entry that
points at a base or mixin controller and remove it from routing.
Keep the class as a base class only, route its concrete subclasses.

---

### 2. `OpenAPIConfig` rejects `openapi_version` below `3.1.0`

`OpenAPIConfig(openapi_version='3.0.3')` now raises `ValueError`.
OpenAPI `3.0.x` was never really supported: it predates JSON Schema,
which is what `pydantic` and `msgspec` generate.

Find every `OpenAPIConfig(...)` with an explicit `openapi_version`
below `3.1.0` and either remove the argument (the default is valid)
or set it to `3.1.0` or newer.

---

### 3. `summary` and `description` are resolved one at a time

`@modify(...)` and `@validate(...)` now resolve `summary` and `description`
independently. Passing one of them no longer drops the docstring for the other.
Both default to `EMPTY` instead of `None`, so an explicit `None`
now means "generate nothing", not "use the docstring".

Find every `@modify` / `@validate` (and `.lazy` variants, and `modify_spec`
of shipped views) that passes `summary=None` or `description=None`
to mean "take it from the docstring" and remove that argument.
Keep `None` only where the intent is to produce no text at all.

---

### 4. Renamed `StreamResponseModification`

`dmr.streaming.metadata.StreamResponseModification` is now
`dmr.streaming.metadata.StreamingResponseModification`.
Rename imports and usages, verify nothing is left:

Before:
    from dmr.streaming.metadata import StreamResponseModification

After:
    from dmr.streaming.metadata import StreamingResponseModification

---

### 5. Removed `dmr.validation.response.ValidatedModification`

The class is gone. Find imports, `isinstance` checks, and annotations
and remove them. Custom response validators should work with
`dmr.metadata.ResponseModification` directly.

---

### 6. `ResponseModification` lost several methods

`build_headers`, `actionable_headers`, `actionable_cookies`,
and `infer_return_type` were removed from `dmr.metadata.ResponseModification`.

Find every call and every override of these methods (custom validators,
custom response specs, tests) and remove or reimplement them
on top of the `headers`, `cookies`, and `return_type` attributes.

---

### 7. Removed `NewCookie.as_dict`

Find every `cookie.as_dict()` call. If the dict was passed
to `response.set_cookie(**cookie.as_dict())`, let `dmr` set cookies
by returning them via `ResponseSpec` / `to_response(cookies=...)` instead.

---

### 8. `secure` and `httponly` cookie flags can no longer be `None`

`NewCookie.secure`, `NewCookie.httponly`, `CookieSpec.secure`,
and `CookieSpec.httponly` must be `bool`. Replace every explicit `None`
with `False`.

Before:
    NewCookie('session', 'abc', secure=None, httponly=None)

After:
    NewCookie('session', 'abc', secure=False, httponly=False)

---

### 9. `Endpoint` objects are not callable

Find every place that calls an `Endpoint` instance directly
(custom controllers, middleware, tests calling `controller.api_endpoints[...]`)
and call its `.func` attribute instead:

Before:
    endpoint(controller, ...)

After:
    endpoint.func(controller, ...)

---

### 10. Auth classes: `security_schemes` and `security_requirements` are methods

For every custom auth class (subclasses of `SyncAuth`, `AsyncAuth`,
and of the shipped token / JWT / session auth classes) rewrite:

- the `security_schemes` property into a method
  `security_schemes(self, metadata, controller_cls)`,
- the `security_requirement` property into a method named
  `security_requirements(self, metadata, controller_cls)`
  that returns a `list[SecurityRequirement]`
  (it can now express both `AND` and `OR` strategies).

Before:
    @property
    def security_requirement(self) -> SecurityRequirement: ...

After:
    def security_requirements(
        self,
        metadata: EndpointMetadata,
        controller_cls: type[Controller[Any]],
    ) -> list[SecurityRequirement]:
        return [...]

Update every direct call of these members in tests.

---

### 11. OpenAPI generators take `metadata` and `controller_cls`

`SecuritySchemeGenerator.__call__` and `ResponseGenerator.__call__`
now accept `metadata` and `controller_cls` parameters.
`ResponseSpec.get_schema` now accepts `controller_cls`
instead of `serializer`.

Find every subclass of these generators and every direct call
of `ResponseSpec.get_schema(...)` and update the signatures:

Before:
    spec.get_schema(serializer=MsgspecSerializer, ...)

After:
    spec.get_schema(controller_cls=MyController, ...)

---

### 12. Autogenerated examples moved to JSON Schema `examples`

Generated examples now land on the JSON Schema `examples` list instead of
the OAS `example` keyword. Examples written by hand are not rewritten.

Regenerate OpenAPI snapshot tests and update any code that reads
`schema['example']` from generated schemas to read `schema['examples'][0]`.

---

### 13. `XML.attribute` and `XML.wrapped` default to `None`

Both are now `bool | None` and default to `None`, so `false` is no longer
dumped into every `xml` object. Both are deprecated in OpenAPI 3.2
in favour of `XML.node_type`. Regenerate snapshots that contain `xml` objects,
prefer `XML(node_type=...)` for new code.

---

### 14. `prefix_encoding` is a list

`MediaType.prefix_encoding` and `MediaTypeMetadata.prefix_encoding`
are now `list[Encoding] | None`.

Before:
    MediaTypeMetadata(prefix_encoding=Encoding(...))

After:
    MediaTypeMetadata(prefix_encoding=[Encoding(...)])

---

### 15. `Parameter.param_in` is a `ParameterLocation`

Find every `Parameter(param_in='query')` style literal in custom
OpenAPI objects and use the `ParameterLocation` enum from
`dmr.openapi.objects` instead.

---

### 16. `load_schema` lost `should_generate_example`, `annotation`, `serializer`

`dmr.openapi.mappers.schema_loader.load_schema` does not accept these
parameters anymore, example generation moved to the schema generator.
Remove the arguments from every call.

---

### 17. Removed `PHONE`, `COLOR`, and `STYLE` from `OpenAPIFormat`

Find every `OpenAPIFormat.PHONE`, `OpenAPIFormat.COLOR`,
and `OpenAPIFormat.STYLE` usage and replace it with the plain string
(`'phone'`, `'color'`, `'style'`), such formats are now loaded as strings.

---

### 18. `SecuritySchemeRegistry.schemes` is a read-only property

It returns registered security schemes sorted by name.
Find every assignment to `registry.schemes` or mutation of it
and register schemes through the registry API instead.

---

### 19. Removed `OpenAPIContext.register_schema`

All custom schema override features are gone. Use the serializer-native
tools instead: `PydanticSchemaGenerator.json_schema_kwargs`
for `pydantic` and `MsgspecSchemaGenerator.schema_hook` for `msgspec`,
or `extra_json_schema` on the model itself.

---

### 20. `SyncOrAsyncAuth.resolve` and `SyncOrAsyncThrottle.resolve` take `is_async`

The `.resolve` parameter changed from `auth_cls` / `throttle_cls`
to a keyword-only `is_async: bool`.

Before:
    auth.resolve(auth_cls=SyncAuth)

After:
    auth.resolve(is_async=False)

---

Finish by running the project's type checker and test suite.
Every removed or renamed symbol from this list must produce no matches
in a project-wide search before the upgrade is complete.
