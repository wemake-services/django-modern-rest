# Upgrade django-modern-rest from 0.7.0 to 0.8.0

Source: CHANGELOG.md, release 0.8.0 (2026-04-26).
Breaking changes for this release are listed in `CHANGELOG.md` under `0.8.0`.

Read this file only while upgrading across this release. Apply every item,
search the whole project (including tests and fixtures) for each one.

## Prompt

Apply this change to the code that uses `django-modern-rest`:
1. Replace `dmr.response.APIRedirectError` with `dmr.response.RedirectTo`
2. Replace `dmr.throttling.backends.DjangoCache`
   with `dmr.throttling.backends.SyncDjangoCache` for sync throttles
   and with `dmr.throttling.backends.AsyncDjangoCache` for async throttles
